BLOC 01
Les Order Blocks
Quand les banques et les gros fonds veulent entrer sur le marché avec des millions d'euros, ils ne peuvent pas juste "acheter" comme toi et moi — leur ordre est trop gros pour être exécuté d'un coup. Ils doivent l'accumuler petit à petit, souvent pendant une phase où le prix a l'air calme ou légèrement à l'inverse du mouvement qui va suivre.

Cette zone où ils ont accumulé leurs ordres, c'est ce qu'on appelle un Order Block. Et bonne nouvelle : elle laisse une trace visible sur le graphique.
💡 En clair : un Order Block, c'est une zone de prix où les gros acteurs du marché ont posé leurs ordres avant un mouvement fort. C'est un peu leur "signature" sur le graphique.
Sur un graphique, un Order Block se repère toujours de la même façon : c'est la dernière bougie avant un mouvement impulsif fort. Regarde ce schéma :
Order Block Bullish = la dernière bougie baissière (rouge) avant une forte poussée haussière. Elle marque l'endroit où les acheteurs institutionnels ont accumulé leurs ordres avant de faire monter le prix.
Ça marche aussi dans l'autre sens :
Order Block Bearish = la dernière bougie haussière (verte) avant une forte chute. Même logique, mais pour les vendeurs institutionnels.
Tu as remarqué la flèche pointillée sur les deux schémas ? C'est le point le plus important à comprendre.
🎯 Les institutions n'arrivent jamais à placer tous leurs ordres d'un coup. Une fois le mouvement lancé, le prix revient souvent sur la zone d'Order Block pour que les gros joueurs puissent finir de remplir leurs ordres restants — avant de repartir dans la direction du mouvement initial. C'est pour ça que cette zone reste importante même après le mouvement.
Attention, toutes les bougies rouges ou vertes ne sont pas des Order Blocks. Pour qu'une zone soit valide, il faut une seule condition :
✅ La bougie doit être suivie d'un mouvement impulsif fort et clair dans une direction. Pas une petite dérive, pas une consolidation molle — un vrai déplacement net, avec des bougies qui s'enchaînent dans le même sens.
Si après ta bougie le prix stagne, hésite, ou avance mollement — ce n'est pas un Order Block valide. C'est ce qu'on va s'entraîner à repérer dans les exercices juste en dessous.
